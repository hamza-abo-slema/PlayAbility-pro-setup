Blind Users Guide (100% Inclusive Accessibility Experience)

Welcome to your safe environment. We designed playAbility pro from scratch to be fully compatible with screen readers (especially NVDA). Here, there is no such thing as an "Unlabeled Button". We programmed the interface to remove Focus from any visual elements that don't concern you, making the keyboard your ultimate maestro. Every movement, edit, and step will be instantly and interactively announced.

1. Basic Playback and Navigation

As soon as you press Enter on any audio or video file in Windows, the software will open, announce the file name, and start playback immediately. The folder containing the file is automatically loaded in the background as a playlist.

  • Navigating files: Use Page Down for the next file, and Page Up for the previous file. For the first or last file, use Ctrl + Home and Ctrl + End.
  • Fast Forward and Rewind: Right Arrow to forward, and Left Arrow to rewind. For longer jumps, press Shift + Right/Left Arrow.
  • Quick Percentage Navigation: Use numbers from 1 to 9 to jump by percentages (e.g., number 5 jumps to 50% of the track). Number 0 returns you to the beginning.

2. Professional Audio and Speed Control

Because you handle audio professionally, we provided flexible controls that go beyond standard limits:

  • Volume Up/Down: Use Up and Down arrows. However, if the file's volume is too low, press Shift + Up Arrow to heavily amplify the sound (up to 400%). To instantly reset the volume to 25%, press Shift + Space.
  • Speed Up and Slow Down: To speed up lectures or slow down clips for precise reviewing, press Ctrl + Right Arrow (to speed up) or Ctrl + Left Arrow (to slow down). The software will announce the current speed (e.g., 1.25x). To return to normal speed, press Ctrl + Down Arrow.

3. Supercharged Sidebar (File and Playlist Management)

This is the heart of the software's file management. If your folder contains thousands of clips, don't waste time searching through Windows. Open the sidebar by pressing Ctrl + L.

First: Searching and Browsing

  • Upon opening the sidebar, your focus will automatically land on a search box. Start typing any letter of the file name, and the software will instantly filter the results in the list below.
  • Press Down Arrow to move into the results list. Navigate with the arrows to hear the file names, and press Enter to play the desired file.

Second: Creating and Managing Playlists

  • Adding a file to a list: Focus on any file in the sidebar and press the Application Key (Menu). You will find the option "Add to custom playlist". Here, you can select an existing list or type a new name to create one instantly.
  • Browsing Custom Playlists: From within the sidebar, you can easily navigate through folders and your created lists.
  • Deleting and Managing Lists: To delete an old list, press the Application Key inside the sidebar and select "Manage custom playlists". A window displaying all your lists will open; select the one you don't want and press "Delete".
  • To exit the sidebar at any time and return to the player, press Escape.

4. The Magic of Editing and Professional Cutting (Lossless)

The software allows you to cut clips at lightning speed, without re-encoding (Lossless), meaning the quality remains 100% original.

First: Selection and Frame-by-Frame Navigation

  • When you reach the desired starting point, press [ to set the start point. It will announce "Start point selected".
  • Move to the end of the segment you want to cut, and press ] to set the end point. It will announce "End point selected" and will start looping the segment. To cancel the selection, press Escape.
  • Frame-by-Frame Navigation: For ultra-precise cutting (down to the letter or word), pause the clip and use Alt + Right Arrow to advance one frame, or Alt + Left Arrow to go back one frame to hear exactly where the audio stops.
  • Fine-Tuning Cut Points: To expand or narrow the selection points precisely, we separated the control for each point for more flexibility:
    • Ctrl + Shift + Right/Left Arrow: Controls Point (A). Left arrow expands it backward, right arrow narrows it forward.
    • Alt + Shift + Right/Left Arrow: Controls Point (B). Left arrow narrows it backward, right arrow expands it forward.

Second: Saving and the Bulk Cut Bin

  • Direct Save: Press Alt + S, and it will prompt you for a save location.
  • Bulk Editing: If you are transcribing a lecture, press Alt + B to add the segment to the bin. Repeat the process to select other clips and press Alt + B.
  • Exporting the Bin: When finished, press Alt + S. A window will open to review and export all clips in the bin at once with sequential numbering.
  • To cancel the current selection, press Escape. To completely empty the bin, press Alt + Shift + B.

5. Audio Engineering and Effects (EQ and Reverb)

To test the audio quality, press Shift + F to open the effects window.

  • You will find two lists: Equalizer (EQ) and Reverb/Spatial Simulation (Reverb Halls).
  • Navigate with arrows to select a filter. The application is instant, and the screen reader will announce the filter's name (e.g., Rock, or Large Hall) so you can hear the difference.
  • Press Enter to save.

6. Integrated YouTube (Search, Play, Subscriptions)

Press Ctrl + Y to open the integrated YouTube interface without complex browsers.

  • Type in the search box and press Enter. Browse the results below. To play a video, press Enter.
  • Advanced Options: Focus on any video and press the Application Key (Menu). You can:
    • Download the video in any quality.
    • Download the clip as audio only (highest quality).
    • Subscribe to the channel to follow it locally in the "Subscriptions" tab.

7. Subtitle Reading and Extra Tools

  • Auto-Subtitles: For movies and anime, press Shift + R, and the screen reader will read the embedded subtitles line by line as they appear. Press Shift + R again to stop.
  • Online Subtitle Search: You can directly fetch subtitles for any movie or anime episode. Press Ctrl + Alt + S to open the search window (the software will auto-fill the current video's name, or you can type it yourself). Browse results with arrows, then press Enter on the appropriate subtitle to download and play it. The file will be saved in the "Subtitles" folder next to the original video, and the screen reader will start reading it instantly.
    Important Note: If the subtitle isn't read automatically after downloading, press Shift + R to activate reading. If a window opens asking you to select a subtitle file from your PC, it means the downloaded file from the internet is corrupted or invalid, and you should try another search result.
  • Time Query: Ctrl + Shift + T announces the elapsed time, and Ctrl + T announces the total duration.
  • Screenshot: If you need to capture a frame from the current video to send to a sighted person, press Ctrl + S, and a high-quality image of the current frame will be saved.

8. Built-in Radio (stations, favorites, recording, scheduling)

Press Ctrl + R to open Radio. Browse Arabic, international, and sports stations, add favorites, record live MP3 audio, or schedule future recordings by day and time.

9. AI Subtitles (transcribe and translate any video)

Press S to transcribe and translate media, save text, and load the result into the player.

10. Smart Silence Skip

Press / to toggle silence skipping, Shift + / for settings, and Ctrl + Shift + . to export a copy without silence.

11. Comprehensive Settings and Customization

Press Ctrl + P to customize language, shortcuts, speech announcements, media keys, playback behavior, backups, audio effects, subtitle reading, and accessibility.

12. Important Extra Features

Manage tracks with Ctrl + Shift + A, cycle audio tracks with Shift + A, convert formats, edit tags, use bookmarks and chapters, and import/export M3U playlists.

Sighted Users Guide (Visual Experience & UI)

Welcome to the world of playAbility pro! We designed the interface here to be a visual masterpiece combining elegance (Flat Design) and ultimate practicality. As soon as you open the software, you'll notice the absence of complex menus and visual clutter. A cinematic black screen, accompanied by vibrant blue buttons and a control bar that interact seamlessly with every mouse movement.

1. Cinematic Interface (Distraction-Free)

  • Smart Auto-Hide: For a pure viewing experience, once you play any video and let go of the mouse for a few seconds, the top bar (containing the file name) and the bottom bar (control bar) will automatically disappear, dedicating 100% of the screen to the video.
  • Smooth Reveal: Move the mouse slightly, and the bars will reappear with a very smooth animation so you can regain control.

2. Mouse Magic (Precise Playback Shortcuts)

  • Zoom In/Out: Double Click anywhere on the video screen to make it Fullscreen, and double click again to return to normal size.
  • Play/Pause: A single Left Click anywhere on the screen pauses the video, and another click resumes playback.
  • Frame-by-Frame Navigation (For Animators and Editors): This is a powerful feature.
    • Alt + Click (Left click with Alt) on the right half of the screen: The video advances exactly one frame.
    • Alt + Click on the left half of the screen: The video goes back exactly one frame.
  • Advanced Mouse Navigation:
    • Standard Forward/Rewind and Jumping: Click the forward/rewind buttons to move by 2 seconds (⏩ / ⏪). Hold the Shift key while clicking to make a long jump of 20 seconds (both values can be customized in settings).
    • First and Last in Folder: Click the next/previous clip buttons (⏭ / ⏮) while holding Ctrl to jump instantly to the last or first clip in the folder.
  • Drag & Seek: You can click and hold the blue progress bar, dragging left and right to smoothly seek through the video.

3. Bottom Control Bar and Interactive Editing Tools

The bottom control bar is your dashboard, designed to give you precise visual feedback for everything happening:

  • Volume Gradient Bar:
    • The base bar color is gray. When you increase the volume with the mouse, it fills with an elegant, vibrant blue gradient, maxing out at 100% in normal mode.
    • The Visual Secret (Boosted Volume): You can hold Shift while dragging the volume bar to boost it up to 400%. When you do this, the volume bar's color will change from blue to a warning red color, visually alerting you that you are in extreme amplification mode.
  • Smart Selection Button (Two dots icon with an arrow between them ↔️):

    This button is dedicated to selecting a specific segment of the clip, operating with a smart interactive technique based on 3 consecutive clicks:

    • First Click (Start Cut A): Upon the first click, the left dot on the button will light up, and a clear red dot will appear on the blue progress bar, indicating the start of the selection.
    • Second Click (End Cut B and Loop): Clicking it again at the desired end point will light up the second dot on the button, turning the entire button red, and a second red dot will appear. At this moment, the software will immediately and continuously loop the segment constrained between the two red dots so you can preview your selection.
    • Third Click (Cancel Selection): Clicking it for the third time (or pressing Escape) will turn off the button entirely, completely canceling the selection, making the red dots disappear, and returning the video to normal playback.
  • Scissors Button ✂️ (Bulk Cut Bin):
    • Normal Click: Saves the constrained segment between the two red dots as a new file in its original quality.
    • Alt + Click (Cut Bin): If you hold Alt while clicking the scissors, the selected clip will be added to the "Cut Bin". You will notice a small red badge appear above the scissors icon displaying the number of clips in the bin, ready to be exported together later.

4. Supercharged Sidebar Management (File Manager)

Click the List button (or Ctrl + L) to slide out an elegant sidebar. This list displays the current folder and manages playlists:

  • Live Search Box: As soon as you type any letter, the list below will update in real-time to show only matching results. An (X) button appears next to the box to clear the search with one click.
  • Create and Save Custom Playlists: Right-Click on any file in the list. Choose "Add to custom playlist". The software will ask you to type a name for the list to create it and add the file.
  • Manage and Delete Playlists: Right-click in any empty space or on any file inside the sidebar and select "Manage custom playlists". A clean window will open displaying all your lists so you can delete what you don't need with a single click.

5. Extra Tools (YouTube, Effects, and Screenshots)

  • Online Subtitle Search: Download subtitles without leaving the software. From the top menu, choose (View -> Subtitles -> Search for subtitles online), or press Ctrl + Alt + S. A search window will appear, automatically pulling the video's name. Select the desired subtitle and click "Download and play subtitle". The subtitle will instantly appear on the screen, and the file will be saved in the "Subtitles" folder next to the original video.
  • YouTube Without a Browser: Via the YouTube button (or Ctrl + Y), a clean window will open to search and watch YouTube. You can right-click any video to reveal a menu to download it or subscribe to its channel.
  • Effects Window (EQ): From the menu Tools -> Audio Effects, or by pressing Shift + F, a window opens to tweak the audio (like Rock or Pop), and the sound will change instantly.
  • Screenshot: Press Ctrl + S at any time. A high-resolution image of the current frame will be captured and saved in your folder.

6. Comprehensive Settings (Ctrl + P)

The settings window includes shortcuts, language, speech announcements, media keys, playback behavior, backup and restore, default Windows app registration, audio effects, subtitle reading, and accessibility options.

7. Extra Features for Sighted Users

Right-click menus, drag-and-drop playlist ordering, clean fullscreen mode, visual cut markers, boosted-volume colors, screenshots, converter, tag editor, bookmarks, chapters, and track management are available from the interface or menus.
